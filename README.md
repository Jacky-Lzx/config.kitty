# Config.kitty

My kitty config.

## Theme

Current theme is [catppuccin mocha](https://github.com/catppuccin/kitty).

You can run `kitty +kitten themes --reload-in=all` (outside tmux) to select a font.

## Font

- English font: [Cascadia Code NF](https://github.com/microsoft/cascadia-code)
- Chinese font: [霞鹭文楷](https://github.com/lxgw/LxgwWenKai)

## External Programs

- fish: `/opt/homebrew/bin/fish`
- nvim: `/opt/homebrew/bin/nvim`
